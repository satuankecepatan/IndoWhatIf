# IndoWhatIf is

not... a good simulator for indonesian elections? i think that's an apt description. it uses (elsim)[https://github.com/endolith/elsim] as the main backbone of the simulator.

it then tries to explain why figures like SBY, Jokowi, and subsequently Prabowo would win their respective eras.

it's (trying) to mathematize the indonesian executive election rules and guidelines.

yeah, try it: `python run_simulations.py`
